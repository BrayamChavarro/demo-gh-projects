# Public examples to show live

Large, active projects where the same tooling is visible at real scale.

## Boards

| Link | What to show |
| --- | --- |
| https://github.com/orgs/github/projects/4247 | GitHub's own public roadmap. Switch between `By Quarter`, `Roadmap` and `Table` views. Hundreds of real issues organized by quarter. |

## Issue forms in production

| Link | What to show |
| --- | --- |
| https://github.com/withastro/astro/issues/new/choose | The template chooser in production. Shows `blank_issues_enabled: false` and the contact links from `config.yml`. |
| https://github.com/withastro/astro/tree/main/.github/ISSUE_TEMPLATE | The source of those templates. Compare against this repository's files. |

Open the Astro link **while signed in**. Without a session, GitHub redirects to the sign-in page and the audience never sees the forms.

## How to use them

Open these in a second window, not instead of your own repository. The pattern is:

1. Show the configuration in your repository, where every option is visible and small.
2. Switch to the public project, where the same tooling carries thousands of real items.
